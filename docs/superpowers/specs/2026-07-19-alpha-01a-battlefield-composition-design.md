# 《废土中继》Alpha 01A：上下攻防构图与单位比例设计

## 1. 阶段定位

MVP 纵切已于 2026-07-19 通过用户验收。Alpha 01A 是进入内容扩充前的战场尺度基线，不新增敌人、协议、房间、素材或系统；它先统一所有后续城区内容必须遵守的空间语言。

## 2. 已确认方向

- 采用“FC 坦克大战的上下攻防构图 + 现代动作肉鸽操控”。
- 中继站位于底部防区，敌军主要从顶部、左上和右上向下推进。
- 玩家保留自由移动、独立 360° 炮塔、冲刺和现有射击方式，不退回四方向移动。
- 普通房允许中继站在底部横向偏移，但不得置于地图中段；敌军不得出生在中继站背后。
- 现有 480×270 逻辑画布和 24×24 地图格保持不变。

## 3. 单位与空间指标

| 对象 | Alpha 01A 指标 |
|---|---|
| 玩家车体实际轮廓 | 约 21–23 像素，约一个地图格 |
| 玩家碰撞盒 | 16×16 像素 |
| 普通敌军 | 保持约 18–22 像素，不大于玩家明显一档 |
| 中继站 | 约 30–36 像素可见轮廓，碰撞不得显著超出画面 |
| Boss | 保持大型单位辨识度，不随普通坦克同比缩小 |
| 普通道路 | 至少两个地图格宽，允许坦克交错和反弹射击 |
| 中继站防区 | 位于底部约两格纵深，玩家出生在其前方或侧前方 |

玩家素材的场景缩放由 `0.75` 调整到 `0.62` 左右；移动动画必须读取场景基准比例，不得在代码中重新硬编码旧比例。

## 4. 三张房间构图

### 首战房：中央防线

- 中继站位于底部中央，玩家出生在其正前方。
- 三个主要出生点位于顶部，少量增援可从左上/右上进入。
- 钢墙形成左右两条纵向引导线，中部砖墙提供可破坏的直达通道。
- 该房负责教授“向上拦截、借墙反弹、必要时拆墙开路”。

### 工业侧翼房：偏置防线

- 中继站位于底部偏左，但仍在底部防区内。
- 敌军从顶部中央、顶部两翼和右上侧翼进入。
- 地形迫使玩家在中央主路与右侧包抄路之间选择，验证基地偏置时的防守优先级。

### Boss 房：中央冲锋轴

- 中继站位于底部中央，Boss 位于顶部中央。
- 第一阶段锚点、哨位和召唤点全部位于上半区。
- 第二阶段打开中央砖墙通道；Boss 沿上下轴冲锋，并在中继站前方钢墙处暴露脆弱窗口。

## 5. 验收标准

1. 玩家进入任意房间后，无需文字说明即可判断敌军从上方来、中继站在下方。
2. 玩家坦克与一格地形接近同尺度，不再遮住两格道路或产生明显的视觉/碰撞错位。
3. 两张普通房的出生点全部位于中继站上方，且导航仍可到达玩家或中继站。
4. Boss 战的第一阶段、中央开路、向下冲锋和钢墙脆弱窗口保持完整。
5. 原有移动、瞄准、射击、反弹、砖墙、奖励、重启和结算规则不发生变化。

## 6. 非目标

- 不生成或替换敌军、地形和中继站素材；素材批量方案在 01A 验收后另行确认。
- 不新增迫击炮车、第三张房间、路线选择、商店、核心模块或局外成长。
- 不修改 480×270 画布、24 像素 TileSet 或战斗数值平衡。
