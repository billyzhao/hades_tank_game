# 《废土中继》封锁城区可交付版收敛设计

> 状态：用户已确认方案方向，等待书面规格复核
> 日期：2026-07-24
> 适用项目：`game1` Godot 4.7 .NET 工程
> 上位策划：[移动核心竞技场肉鸽重设计](2026-07-20-mobile-core-arena-roguelite-redesign.md)
> 上位技术：[移动核心竞技场技术设计](2026-07-20-mobile-core-arena-technical-design.md)

## 1. 收敛决定

项目暂停第二至第五竞技场的内容生产，把封锁城区作为唯一当前交付目标。现阶段不以“完成五张地图的内容量”为成功标准，而以“封锁城区能够独立证明玩法、构筑、美术、音频、手感和工程质量”为成功标准。

长期五竞技场设计继续保留，但全部降为封锁城区试玩版通过后的扩展方向。现有多竞技场数据结构、索引和资源接口继续保留，不为单区试玩进行破坏性回退；玩家可见流程不再进入空白的第二竞技场占位。

## 2. 产品交付目标

交付一份可以独立启动和反复游玩的 Windows 试玩版。一局目标时长约 12～18 分钟，正式流程为：

`标题/开始 → 核心选择 → 封锁城区五波 → 即时属性升级与波间奖励 → 第五波精英 → 路障指挥车 Boss → 封锁城区结算 → 重开/退出`

试玩版需要验证四件事：

1. 坦克移动、独立瞄准、射击、冲刺和原地重启是否具有持续游玩的操作乐趣；
2. 三核心、即时属性、协议和辅助系统能否形成可辨识且可重复尝试的构筑；
3. 四种敌军、精英、五波导演和 Boss 能否形成逐步升级的战斗节奏；
4. 黄沙工业像素风、战斗特效、UI 和音频能否形成统一且达到对外展示水平的表现。

## 3. 当前保留范围

### 3.1 核心玩法

- 玩家坦克是唯一失败目标；
- 三种初始核心，每个核心保持约三条可行构筑方向；
- 手动主炮、核心冲刺、最多两个自动辅助槽；
- 战斗数据掉落、靠近吸附、完全暂停即时升级；
- 五个限时增援波次，刷新结束后必须清空残敌；
- 第五波包含一名具有单条额外规则的精英；
- 波间协议、维护和稀有奖励；
- 同图进入路障指挥车 Boss；
- Boss 击败后全修装甲并进入正式单区结算。

### 3.2 封锁城区内容

- 75%～85% 连续开阔区域；
- 3～5 组短时战术障碍岛；
- 四周安全出生入口和明确刷新预警；
- 侦察、巡逻、突击、迫击四种职责；
- 过载精英；
- 路障部署、火力哨位、冲锋和弱点窗口组成的 Boss 战；
- 可破坏墙、固定钢墙和 Boss 动态路障。

### 3.3 交付体验

- 标题、开始、暂停、失败、完成结算和重新开始流程；
- 正式 HUD、升级界面、奖励卡片和 Boss 状态；
- 键鼠操作完整，验收菜单只保留在 Debug 流程；
- 封锁城区正式音效、环境声和战斗音乐；
- 可独立运行的 Windows 构建。

## 4. 延后范围

以下内容不进入当前排期：

- 废弃工厂、干涸水库、军阀要塞、移动堡垒；
- 后四个 Boss 及其专属敌军、地形、机制、素材和音频；
- 五竞技场完整单局和跨区平衡；
- 局外永久数值、叙事、挑战词条和完整横向解锁；
- 商店、货币、装备背包、独立武器库存；
- 在线多人、完全程序生成地图和第二主动技能；
- 没有性能证据时的 ECS、通用对象池或依赖注入重构。

延后不是删除。后续扩展必须复用封锁城区验证通过的玩法、资源和测试边界，不得在当前阶段提前建设空接口或占位内容。

## 5. 单地图重复感控制

当前不通过制作新地图解决重复感。封锁城区优先依靠以下层次形成局内变化：

1. 四周入口、波次编队和同时压力方向变化；
2. 侦察追踪、巡逻射击、突击压迫和迫击范围控制的职责组合；
3. 第五波精英额外规则；
4. 可破坏掩体和 Boss 动态路障改变局部空间；
5. 三核心、协议和辅助系统改变玩家输出与生存节奏；
6. Boss 两阶段把普通波次规则转化为冲锋回避和弱点输出窗口。

只有完整试玩验证仍显示明显空间疲劳时，才新开方案讨论“同主题布局变体”。当前不承诺随机地形、程序生成或多张城区地图。

## 6. 收敛迭代

### BC-01：正式单区流程与节奏收口

目标是把现有功能纵切改成完整玩家流程：

- 移除第二竞技场玩家可见占位；
- 补齐标题、开始、暂停、失败、完成结算和重开；
- 调整五波时长、刷新、清场、奖励和 Boss 衔接节奏；
- 检查入口、障碍、导航和清场不会卡局；
- 建立正式试玩与 Debug 验收模式的边界。

验收结果：不开验收菜单也能完成一整局，并清楚知道为什么胜利或失败。

### BC-02：战斗、敌军与构筑深化

目标是证明核心玩法具有可玩性：

- 校准三核心操作节奏和约三条构筑路线；
- 校准即时属性、16 个普通协议、4 个稀有协议和四种辅助；
- 让四种敌军的移动、射击、轮廓和预警具有清晰职责；
- 完成精英强度和第五波组合；
- 完成 Boss 两阶段、哨位、路障、冲锋、弱点和击毁节奏；
- 进行多种种子与多核心试玩，删除无效、必选或明显死亡选项。

验收结果：不同核心和奖励选择会显著改变打法，难度来自组合压力而不是单纯堆血。

### BC-03：封锁城区正式美术

目标是让封锁城区范围内的主要玩家可见素材不再依赖占位表现：

- 正式玩家车体、炮塔及三核心视觉差异；
- 独立侦察单位，解除与巡逻坦克共用贴图；
- 玩家、普通敌军、精英、Boss 和辅助系统的最小动作反馈；
- 炮口焰、弹道、命中、击毁、扬尘、冲刺、受击、重启、升级和战斗数据；
- 迫击、刷新、路障、冲锋、弱点和阶段转换预警；
- 正式 HUD 图标、经验条、核心/辅助/协议状态、奖励卡和结算界面。

素材继续执行“小样确认 → 同批扩展 → 游戏内可读性验证”。封锁城区交付范围内不得把 `MISSING`、`PROVISIONAL` 或 `PARTIAL` 误写为完成。

### BC-04：音频、手感与玩家体验

目标是建立完整的操作反馈和危险信息层级：

- 履带、主炮、冲刺、受击、装甲危险、重启；
- 四类敌军开火和关键预警；
- 精英过载、Boss 入场、路障、哨位、冲锋、弱点和击毁；
- UI 移动、确认、升级、维护、失败和完成；
- 黄沙工业环境声、五波战斗音乐和 Boss 过渡；
- 屏幕震动、命中停顿、闪光和危险提示只在不影响瞄准时使用；
- 检查 HUD 遮挡、文字层级、暂停输入和键位冲突。

验收结果：重要状态不需要依赖日志或 Debug 文本才能理解。

### BC-05：平衡、稳定与交付候选版

目标是完成 Release Candidate：

- 三核心、多种种子和不同构筑的完整试玩；
- 难度曲线、奖励频率、维修保障和 Boss 时长调整；
- 敌军卡地形、出生重叠、残敌不结算和异步状态回归；
- 目标压力下的帧率、活动炮弹和持续特效验证；
- 全量 C#、Godot headless、集成和实际运行回归；
- Debug/Release 边界检查；
- Windows 构建、版本信息、启动说明和已知限制；
- 策划可见验收清单与最终素材清单同步。

验收结果：试玩构建不依赖 Godot 编辑器，可以从开始连续游玩到结算并稳定重开。

## 7. 技术边界

本次收敛不改变已经确认的架构：

- `RunState` 保存单局事实；
- `ArenaController` 负责封锁城区五波、奖励和 Boss 状态；
- `WaveDirector` 负责刷新时间、入口和存活敌军；
- `BuildController` 与 `RewardController` 负责构筑和候选；
- `PlayerTank` 不硬编码具体协议或竞技场规则；
- 静态内容使用只读 Godot `Resource` / `.tres`；
- `AppRoot` 只负责组合、事件转发和界面切换。

多竞技场索引和资源结构继续保留为扩展点，但当前 Release 流程在竞技场 1 完成后进入单区结算。禁止为了快速交付把奖励、波次、Boss 或结算规则重新集中硬编码进 `AppRoot`。

## 8. 美术与素材边界

封锁城区是唯一允许继续生产正式运行素材的竞技场。素材优先级为：

1. 玩家坦克与三核心；
2. 独立侦察单位和敌军职责补齐；
3. 战斗与 Boss 关键预警特效；
4. 正式 HUD、图标、卡片和结算；
5. 音效、环境与音乐；
6. 非关键装饰和可选细节。

第二至第五竞技场素材统一标记为延期，不生成样图、不加工运行资源、不下载或购买第三方包。

## 9. 测试与验收

### 9.1 自动化门禁

- 纯 C#：状态机、经验、奖励、构筑、维修、重启和确定性；
- Godot headless：五波、暂停、升级、入口安全、敌军弹道、精英、Boss、结算和重开；
- 资源扫描：运行引用、素材状态、无中继站资产和 Debug/Release 边界；
- 集成压力：目标敌军、炮弹和持续特效规模下无卡死、崩溃或明显帧率异常。

### 9.2 策划可见验收

- 正常模式完整打一局；
- Debug 模式快速跳转核心、波次、精英、Boss、失败和结算；
- 验收说明统一使用“操作 → 预期画面/数值/状态变化”；
- 自动化不能替代实际 Godot 运行和玩家可见验收。

### 9.3 完成定义

封锁城区只有同时满足以下条件才算可交付：

1. 不依赖 Debug 菜单即可完成正常单局；
2. 不存在玩家可见占位地图或占位结算；
3. 三核心和主要构筑路线可辨识、可用且没有明显死选项；
4. 敌军、精英和 Boss 职责与预警清楚；
5. 不存在卡出生、卡地形、残敌卡结算或 Boss 阶段卡死；
6. 封锁城区主要运行素材、关键特效、正式 UI 和音频完成；
7. 目标压力下稳定运行；
8. 自动化、Godot 实机、素材和策划验收全部通过；
9. Windows 构建可独立启动、完成、失败、结算和重开。
