# BC-05A Debug 策划节奏调参台执行计划

## 目标

给策划提供一套只在 Debug 可见的实时节奏调参工具，并允许把确认参数安全保存成 Release 使用的正式资源。

## 实现顺序

1. 新增带范围校验的 `BlockadeCityBalanceProfile` 和默认 `.tres`；
2. 新增运行时不可变参数快照与编辑器 Debug 安全保存服务；
3. 让 `WaveDirector`、新出生敌军、玩家移动和武器冷却消费同一快照；
4. 将 `AcceptanceMenu` 改为双页容器布局，增加参数步进、预设、恢复、复制与二次确认保存；
5. 由 `AppRoot` 绑定请求、应用参数、提供实时状态并回显保存结果；
6. 补充纯 C#、菜单、导演、敌军、玩家、保存边界和 Release 回归；
7. 全部开发结束后执行集中功能自检，再交付用户验收。

## 完成门禁

- 默认 Profile 不改变当前正式玩法；
- 参数范围、预设和工作副本确定可测；
- 保存成功必须可重新加载验证，保存失败不得显示成功；
- Release 不显示菜单、不开放写盘、仍读取正式 Profile；
- 现有功能测试与 Windows Release 冒烟通过；
- 用户验收通过前不提交、不推送。
