# BC-03 封锁城区正式美术实施计划

**目标：** 在不改变 BC-01/BC-02 玩法、数值和架构的前提下，把封锁城区玩家主要可见内容从占位/过渡表现升级为同一套黄沙废土工业像素街机风格，并完成实机可读性验证。

## 范围

- 保留已确认的封锁城区地面、钢墙/砖墙、三类普通敌军、过载精英、Boss 拆件和四辅助部件。
- 生产并接入正式玩家车体、炮塔和三核心差异组件。
- 生产独立侦察单位，解除与巡逻坦克共用贴图。
- 生产并接入炮口、命中、击毁、扬尘、冲刺、受击、重启、升级、战斗数据和 Boss/迫击关键预警。
- 补齐 HUD、经验、三核心、属性、部门、辅助、波次/精英、奖励卡和结算的正式图标与状态层。
- 更新 `asset_sources/GAME_ASSET_CATALOG.md`、批次 README 和运行资源登记。

## 非范围

- 不制作第二至第五竞技场素材。
- 不改变五波、敌军职责、构筑权重、Boss 状态机或当前数值。
- 不接入音频；音频、震动和最终手感属于 BC-04。
- 不把 Debug 策划验收菜单包装成正式玩家 UI。

## 素材流水线

1. 以用户已确认的 Batch 01 第二版玩家样张、Batch 06 地面/敌军和 Batch 07 工业 UI 为视觉基准。
2. 新建 Batch 08，仅生产本计划缺口；原始图使用内置图像生成，固定洋红背景并保存完整提示词。
3. 使用确定性脚本完成去底、分格、缩放、命名与边界检查；脚本不得重新绘制美术。
4. 源图和处理结果进入 `asset_sources/ai_generated/batch-08-blockade-city-final-art/`，通过检查的运行图进入 `game1/assets/`。
5. 游戏内接入后更新主清单；用户验收前新素材只能标记为 `CANDIDATE` 或 `PARTIAL`。

## 实现顺序

1. 玩家车体/炮塔、三核心组件与独立侦察单位。
2. 基础战斗、状态反馈和关键地面预警特效。
3. HUD/奖励/结算图标和工业状态样式。
4. 资源引用扫描、集中构建、Headless 套件和 Godot 可见试玩。

## 完成门禁

- 三核心在坦克本体、HUD 和核心选择中均可仅凭图形/色彩辨认。
- 侦察单位与巡逻坦克不再共用运行贴图。
- 开火、命中、击毁、移动、冲刺、受击、重启、升级和战斗数据都有可见正式反馈。
- 迫击、刷新、路障、Boss 冲锋、弱点和阶段转换的危险层级清楚。
- HUD、奖励卡和结算不再只靠纯文字/基础控件表达关键状态。
- 480×270 逻辑画布和 1440×810 验收窗口下无遮挡、无明显缩放模糊、无素材丢失。
- 运行引用与素材主清单一致；BC-03 集中自检通过后再交给用户一次性验收。
