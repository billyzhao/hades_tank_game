# Alpha 01A：上下攻防构图与单位比例 Implementation Plan

## 目标

在不改变玩法规则的前提下，建立可复用的城区战场尺度：一格一车、底部中继站、上方来敌，并将现有两张普通房和 Boss 房全部迁移到该构图。

## 实现顺序

1. 玩家场景缩放到 `0.62` 基准、碰撞盒调整为 16×16，炮口位置匹配新轮廓。
2. `TankVisualAnimator` 从场景读取车体基准比例，运动脉冲只叠加微小偏移。
3. 重构首战房为底部中央基地与顶部三路进攻。
4. 重构工业侧翼房为底部偏左基地与上半区侧翼进攻。
5. 重构 Boss 房为顶部 Boss、底部中央基地与中央冲锋轴；同步锚点、路障、开路格、哨位和召唤点。
6. 增加 headless 构图契约检查，更新 README 和迭代记录。
7. 根据 OpenGL 实际渲染帧调整 HUD 安全区，确保上方出生预警与顶部中央 Boss 不被遮挡。
8. 开发全部完成后统一执行构建、单测、相关 headless 套件、主场景冒烟和可见自检。

## 禁止方式

- 不以修改镜头缩放伪装坦克变小。
- 不改变 TileSet 格子尺寸或逻辑画布。
- 不把房间坐标写入运行时代码；布局继续由场景和 `RoomDefinition` 数据拥有。
- 不新增敌人、素材或构筑内容。

## 验收入口

- 正常开局连续查看首战房与奖励后的工业侧翼房。
- 右上角“Boss 验收”直接查看 Boss 房上下轴构图。
- F8 调试面板辅助确认敌军数量和房间状态，不替代肉眼构图验收。
