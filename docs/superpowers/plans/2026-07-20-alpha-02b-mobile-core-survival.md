# Alpha 02B：移动核心生存基础执行计划

> 上位依据：`2026-07-20-mobile-core-arena-roguelite-redesign.md`、`2026-07-20-mobile-core-arena-technical-design.md`、`2026-07-20-mobile-core-arena-roadmap.md`。本计划不扩大 Alpha 02B 范围。

## 目标

玩家坦克成为唯一战斗生命线；独立中继站从生产运行时、场景、HUD、敌军/Boss 目标、协议、结算、存档摘要和测试中完整移除。坦克报废时消耗一次重启并在原地完成 1.2 秒重构，恢复向上取整的 50% 装甲、释放无伤击退脉冲并获得 2 秒保护；没有重启时本局失败。

## 非目标

不实现五波计时、经验升级、核心选择、新敌军、四周增援、协议三阶、维护奖励或新 Boss 内容；不重做 Alpha 01A 已确认的玩家一格比例；不新增依赖或改变 Godot/.NET 版本。

## 执行顺序

### 1. 测试先行：领域与迁移

- 更新纯 C# 测试，先验证攻城单位也只选择玩家、旧 `RelayIntegrity` 不再是领域状态、默认一次重启且不为负、50% 恢复向上取整、Boss 后全修不恢复次数；
- 新增 schema 1→2 迁移测试，确认设置与解锁保留、旧中继耐久忽略；
- 先运行定向测试并观察正确失败，再实现最小领域代码。

### 2. 领域状态和存档

- `RunState` 增加最大装甲与显式同步/维修/重启恢复/下一区全修接口，删除中继耐久；
- `RunController` 只通过玩家报废裁决重启或失败；
- `RunResultSnapshot` 与 `LastRunSummary` 改为核心、竞技场、波次、等级和耗时摘要；
- schema 升为 2，读取 schema 1 时迁移，继续使用原子写入。

### 3. 生产运行时解除中继依赖

- 删除 `RelayStation` 节点、脚本、图片和两个旧中继协议资源；旧 Id 不复用；
- 普通敌军和 Boss 只以玩家为战斗目标；路障部署只保护玩家占用格；
- `HealthComponent` 从 `RunState` 初始化，并把每次装甲变化同步回 `RunState`；
- `RoomController` 不再把第二实体作为失败源。

### 4. 原地重启闭环

- `RebootController` 由 `AppRoot` 注入正式 `RunController`/`RunState`，不读取中继节点；
- 记录并保持原坐标，重构期间关闭移动、射击和碰撞；
- 不清理整场或附近炮弹；恢复 50% 装甲后只击退范围内普通敌人；
- 恢复控制并给予 2 秒保护，状态通过 HUD 和事实信号可见。

### 5. HUD 与策划验收入口

- 删除中继 HUD，显示装甲、重启、移动核心占位状态、敌军和当前旧房间/波次迁移信息；
- 新增 Debug 可见的“生存验收”按钮和面板，提供装甲 -25、触发报废、重新开始；
- 面板通过正式伤害/重开入口驱动，不直接改写私有字段；
- 结算文案改为玩家突围/报废，不出现基地或护送。

### 6. 集中验证

- 纯 C#：领域、目标、迁移全部通过；
- headless：三个房间无 `RelayStation`/中继 HUD，敌军只选玩家，原地重启坐标不变、50% 装甲、2 秒保护、无伤击退；
- 构建与旧相关套件通过；
- OpenGL Compatibility 启动，使用可见验收面板复核装甲、重构、保护和失败；
- 全量自检只在上述开发完成后执行。

## 文件边界

允许修改：`game1/scripts/run/`、`app/`、`combat/`、`enemies/`、相关 Boss/表现/UI 脚本，三个房间场景、主场景、存档/协议资源、测试、README、素材登记和本迭代记录。

允许删除：`RelayStation.cs(.uid)`、`relay_station.png(.import)`、两个旧中继协议资源、已被 Gate 0 取代的未跟踪 `batch-00-style` 图像/提示词目录。

禁止修改：引擎版本、.NET 目标、外部依赖、Alpha 02C 及后续功能。

## 用户验收标准

1. 启动后 HUD 没有中继站或第二生命值；
2. 点击“生存验收”可见面板，不依赖 F1/F8/Z/X；
3. 装甲 -25 后 HUD 与玩家装甲同步；
4. 第一次报废：坦克不换位置，重构约 1.2 秒，恢复 50/100，重启从 1 变 0，保护约 2 秒；
5. 保护期伤害不生效，普通敌人被脉冲推开但不受伤；
6. 第二次报废：不再复活，本局失败并出现无基地语义的结算；
7. Boss 和普通敌人均只攻击玩家。
