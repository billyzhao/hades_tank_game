# Alpha 02C：五波稀疏竞技场

状态：开发自检完成，等待用户验收

## 目标

在同一封锁城区竞技场完成五个限时波次、残敌清场、波间确认和第 5 波精英槽位，并把旧通道式房间替换为极稀疏竞技场灰盒。

## 非目标

- 不实现经验、即时属性升级和波末数据回收；
- 不实现三核心、三阶协议、维护效果和正式奖励池；
- 不新增四类城区敌人、正式精英词条或 Boss 战；
- 不进行 Alpha 08 的全量敌军/炮弹压力测试；
- 不批量生成 Batch 2 地形素材。

## 验收标准

1. HUD 显示 `竞技场 1/5`、`波次 1/5`、刷新秒数、存活敌军和刷新/清场状态；Debug 验收菜单提供结束刷新、敌军全灭、结束本轮并结算、确认并到下一波和结束本局命令；
2. 正常五波配置依次为 45/50/55/60/70 秒；
3. 刷新时间归零后不再生成，但场上敌军不会被自动删除；
4. 残敌全部击毁后才显示奖励确认；
5. 确认前四波奖励进入下一波，第 5 波确认后显示 Boss 即将进入；
6. 第 5 波存在明显金色精英槽位，精英未死时不能结算；
7. 地图中心开阔，仅四个小型障碍岛，主要通路不小于三台玩家坦克宽；
8. 四周入口均在墙体内侧开放出生带；每次生成都必须通过玩家安全距离、16×16 地形/边界碰撞净空和到玩家的导航可达性检查，否则跳过本次生成；
9. 玩家装甲、原地重启和失败规则保持 Alpha 02B 行为；
10. 自动化、Godot 启动及策划可见验收均通过。

## 用户验收

待执行；用户验收前不得提交或推送。

1. 启动 `game1/project.godot`，等待开场约 0.6 秒；HUD 应显示 `竞技场 1/5` 与 `波次 1/5`。
2. 观察敌军从四周入口刷新；打开右上角 `竞技场验收`。点击“结束刷新（保留残敌）”应停止计时且场上残敌仍保留；点击“敌军全灭（当前波）”后应出现波间确认面板。
3. 点击“结束本轮并结算”可一键验证清场门禁；点击“确认并到下一波”可从战斗、清场或奖励阶段快速进入下一波。两者只在 Debug 验收菜单中有效，不改变正常游戏规则。
4. 第 5 波观察金色精英；精英未被击毁前不得进入奖励。击毁并确认后，应显示 Boss 即将进入的占位提示。
5. 点击“结束本局（验收）”应显示失败结算；验证场地中央开阔、仅四处小障碍岛，坦克可在横纵主通路连续快速机动；正常受击/重启/失败行为保持 02B。
