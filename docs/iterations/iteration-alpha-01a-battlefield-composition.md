## 目标与非目标

- 目标：玩家约一格大小，中继站处于底部防区，普通敌军从上半区推进。
- 目标：重构两张普通房与 Boss 房，同时保持现有玩法闭环。
- 非目标：新敌人、新房间、新素材、四方向操控或画布变更。

## 策划验收标准

| 操作 | 预期画面与状态 |
|---|---|
| 进入首战房 | 中继站位于底部中央，玩家在其前方，敌军从顶部三路向下推进 |
| 观察坦克与墙格 | 玩家约占一格，碰撞与轮廓接近，不遮住两格通道 |
| 进入第二房 | 中继站位于底部偏左，敌军仍只从上半区进入，房间动线不同于首战房 |
| 点击 Boss 验收 | Boss 在上、中继站在下；二阶段沿中央轴冲锋并撞击防区钢墙 |
| 完成常规操作 | 自由移动、独立瞄准、反弹、砖墙、奖励、重启和结算保持不变 |

## 实现摘要

- 玩家车体/炮塔基准缩放改为 `0.62`，碰撞盒改为 16×16，默认朝向上方；移动动画读取场景比例。
- 首战房改为底部中央中继站、顶部三路与上方两翼来敌。
- 工业侧翼房改为底部偏左中继站、顶部与右上侧翼来敌。
- Boss 房改为顶部 Boss、底部中央中继站、两格中央开路和防区钢墙碰撞轴。
- 三张房统一复用 `arena_bounds.tscn`，禁止玩家和敌军驶出画面；HUD 左上面板收窄，为顶部中央 Boss 和上方出生预警留出可见安全区。
- `navigation_grid` headless 套件增加玩家尺度、普通房上下构图/导航、Boss 中央冲锋轴检查。
