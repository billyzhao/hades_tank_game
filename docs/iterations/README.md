# 迭代执行记录

每个正式开发迭代从 [`_template.md`](_template.md) 复制一份记录，命名为 `iteration-NN-<topic>.md`。记录只保存执行证据，不替代策划、技术或开发计划；方案发生变化时必须同步修改真正的权威文档。

状态顺序固定为：策划前置 → 测试前置 → 开发理解 → 开发 → 架构合规 → 测试后置 → 策划复验 → 主智能体自检 → 用户验收 → 提交/推送。
