## 目标

将 Alpha 02F、02G、02H 合并为一次用户验收：封锁城区完成“核心选择 → 五波 → 奖励/维护/即时升级 → 四类敌军与精英 → 同图 Boss → 装甲全修 → 第二竞技场占位”的玩家可见闭环。

## 实现范围

- 四种自动辅助系统、两槽位、重复升级和满槽奖励池过滤；
- 侦察无人机、巡逻坦克、突击车、迫击炮车；四向安全入口、预警生成、导航与净空检查；
- 第五波单精英规则：过载加速后冷却减速；
- 路障指挥车在当前封锁城区动态入场，不切换独立 Boss 房；保留可破坏地形；
- Boss 击败后清理临时战斗实体、全修装甲、保留重启次数并进入竞技场 2 占位；
- Debug 验收入口提供波次推进、敌军清场、经验和辅助授予，且不写私有单局字段。

## 非目标

- 第二至第五竞技场的实际内容；
- 新的普通敌军行为、商店、装备背包或局外永久数值；
- Alpha 08 前的性能优化和完整压力调参；
- 未确认的新素材、外部依赖或素材采购。
