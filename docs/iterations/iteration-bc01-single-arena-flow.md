- 结果摘要记录真实核心、协议、等级、区域和耗时；重试与返回整备均从标题入口重新开始。
- 胜利或失败结果页持有独立 `RunResult` 暂停，战斗、输入和计时器不会在结算背后继续运行。
- 移除玩家可见的第二竞技场、Alpha 03 和 Boss 占位文案。
- HUD 区域名统一为“封锁城区”；策划验收菜单和 F8 调试层只允许 Debug 构建使用。
- 增加单竞技场闭环测试，保护五波、Boss、结果页和标题入口契约。

## 用户验收标准

1. 启动项目后先看到“废土中继 / 封锁城区 · 单竞技场交付版”，战斗保持暂停。
2. “进入封锁城区”进入三核心选择，“退出游戏”可关闭游戏。
3. 选择核心后第一波正常开始，HUD 显示“封锁城区”，不再显示“竞技场 1/5”。
4. Debug 构建可用右上“竞技场验收”的“确认并到下一波”快速完成五波；正式 Release 不应显示该入口。
5. 完成第五波奖励后进入路障指挥车 Boss；可立即点“击败 Boss（验收）”，应显示“封锁城区突破”结果页。
6. 结果页显示本局核心、协议、等级和耗时，不进入第二竞技场占位。
7. “重试本局”或“返回整备”均回到标题入口，可重新选择核心。
8. 坦克重启耗尽导致失败时显示失败结果页，也可重新开始。
