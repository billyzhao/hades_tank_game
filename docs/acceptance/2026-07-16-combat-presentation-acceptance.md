# 混合表现迭代验收脚本

项目入口：`game1/project.godot`。运行主场景后按下列步骤验收；本轮重点是表现，不改变第五迭代的伤害、波次与重启规则。

## 1. 静止画面

- 操作：启动后不输入，观察战场和 HUD。
- 预期：画面为黄沙废土工业区；主角是沙黄/深灰重型坦克；中继站有绿色能量核心；砖墙红褐、钢墙蓝灰并有危险条纹；HUD 为两行三列军工面板，不遮挡中继站。

## 2. 移动、瞄准与冲刺

- 操作：用 WASD/方向键移动，同时用鼠标绕主角移动准星；按空格冲刺。
- 预期：车体朝移动方向转动，炮塔独立朝向鼠标；移动时车体有轻微履带节奏与重量摇晃；冲刺产生更密集的沙尘。

## 3. 开火与命中

- 操作：按住鼠标左键，分别射向钢墙、砖墙与敌军。
- 预期：成功开火才出现炮口火光、炮塔后坐、炮弹拖尾、轻微震动和开炮声；钢墙命中为蓝白火花并反弹；砖墙和敌军命中为金色火花，摧毁时出现更大的橙红爆炸与震动。

## 4. 敌军职责与预警

- 操作：等待三类敌军进入战场并接近攻击距离。
- 预期：黄=巡逻追玩家、橙=突击快速压迫、紫=攻城优先中继站；敌人移动方向可读，攻击前出现职责色预警环与白闪。

## 5. 双生命线反馈

- 操作：按 Z 触发玩家受伤；按 X 触发中继站受伤；再次按 Z 验证重启。
- 预期：玩家受击红闪、中继站受击亮绿闪并播放提示声；HUD 数值同步变化；坦克报废后仍按原规则消耗一次重启，1.2 秒后在中继站旁恢复 50% 装甲。

## 6. 音效与清场

- 操作：按 M 静音，再次按 M 恢复；完成三波战斗。
- 预期：M 只控制 SFX，不改变玩法；清完第三波后 HUD 显示房间已清场，事件栏显示房间完成，控制台无持续报错。
