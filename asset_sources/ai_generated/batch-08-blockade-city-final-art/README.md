# Batch 08：封锁城区正式美术

> 生成日期：2026-07-24
> 工具：Codex 内置 `image_gen` + `generate2dsprite.py` 确定性后处理
> 当前状态：2026-07-24 用户验收通过，已允许登记为 `CONFIRMED`

## 1. 批次范围

- 玩家正式底盘、独立炮塔、通用核心和三种移动核心；
- 独立侦察无人机；
- 玩家/敌军弹道，炮口、命中、击毁、扬尘、冲刺、受击、重启、升级和战斗数据；
- 普通刷新、迫击炮、路障、Boss 冲锋、阶段转换和击毁预警/反馈；
- 装甲、重启、波次、精英、三核心、辅助、五项即时属性和四部门图标。

完整生成提示词见 [`PROMPTS.md`](PROMPTS.md)。原始母版保存在 `raw/`，确定性切片和检查记录保存在 `processed/`。

## 2. 加工规则

1. 所有母版以固定 `#FF00FF` 洋红底生成；
2. 使用 `generate2dsprite.py process` 去底、分格、统一缩放并输出透明 PNG；
3. UI 和主要特效启用边缘触碰拒收，最终采用组的 `pipeline-meta.json` 均为 `edge_touch_frames: []`；
4. 运行文件复制到 `game1/assets/sprites/`，文件名按玩法语义命名；
5. 图片不承载碰撞、伤害、波次、状态机或奖励规则。
