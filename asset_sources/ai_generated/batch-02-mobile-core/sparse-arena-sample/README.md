# 封锁城区稀疏竞技场样图（v1）

这是 Alpha 02C 的 Batch 2 视觉验收样图，用于确认正式竞技场的整体比例、开放度与环境语言；**尚未进入游戏运行时素材目录**。

- 画面保持 Gate 0 的明亮黄沙、深色工业边框与高可读性街机风格。
- 场地中央保持连续开放，四角/边侧仅有四组小型障碍岛；没有长墙、迷宫、狭窄通道或中继站/基地。
- 东、南、西、北四侧各有一个低调的工业入口灯具，作为刷怪入口的环境表达。
- 当前运行时仍使用 `TileMapLayer`、碰撞层和导航网格实现地图；本图仅作美术比例与后续可替换环境底图的依据，不承载碰撞或玩法数据。

待用户确认本样图后，才可继续扩展 Batch 2 环境素材；确认前不得复制到 `game1/assets/` 或直接替换运行时地图。
