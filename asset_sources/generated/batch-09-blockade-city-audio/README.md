## 内容

- 敌军：四职责开火、刷新预警、普通击毁和精英过载；

## 生产规则

- `generate_audio.py` 使用固定种子和纯标准库生成 16-bit PCM WAV；
- 短音效为 22050 Hz 单声道；音乐与环境为 22050 Hz 双声道；
- 战斗基础层和强度层同为 120 BPM、16 拍、8 秒，运行时同步启动并只调整强度层音量；
- 脚本输出 `manifest.json`，记录文件名、用途、声道、采样率、时长和来源；
- 运行文件复制到 `game1/assets/audio/blockade_city/`，不覆盖源批次。

## 门禁

- 生成清单与运行目录一一对应；
- 峰值不削波，循环文件首尾经过短交叉淡化；
- 高频重复音效使用变体或轻微音高变化；
