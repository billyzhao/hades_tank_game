# 废土中继：Godot 可执行项目

Godot 4.7 .NET / C# 制作的俯视角坦克肉鸽项目。

## 版本边界

当前工作区正在实施 **Alpha 02B：移动核心生存闭环**：玩家坦克是唯一战斗生命线，中继站实体、基地血条与基地目标已经移出生产运行时；历史房间、协议奖励和 Boss 仍暂作后续竞技场重构的迁移骨架。

已经确认但尚未完成实装的目标版本是：

- 玩家坦克是唯一战斗主体，不存在独立中继站、基地血条或守卫结局；
- 一局包含 5 座竞技场，每座竞技场 5 波敌军，随后进入 1 场 Boss 战；
- 击杀经验推动战斗内即时升级，升级界面完全暂停战斗；
- 开局选择一种核心，核心固定操作节奏，同一核心支持约三条构筑路线；
- 统计强化、部门协议、维护奖励和 Boss 奖励共同组成受控随机构筑；
- 坦克原地重启，不回到基地或中继站旁。

完整目标以仓库根目录的移动核心竞技场策划、技术设计和路线图为准。

## 启动

从仓库根目录执行：

```powershell
dotnet build game1/Game1.csproj --nologo
godot --path game1
```

如果 Vulkan 管线异常，使用：

```powershell
.\game1\run-editor-opengl.cmd
.\game1\run-game-opengl.cmd
```

## 当前操作与验收入口

- WASD / 方向键：移动
- 鼠标 / 右摇杆：独立瞄准
- 鼠标左键：射击
- 空格：冲刺
- Esc：暂停或继续
- F8：显示或隐藏调试信息（仅调试构建）
- M：切换 SFX 静音

右上角常驻“生存验收”按钮会展开策划验收菜单，可执行正式伤害、坦克报废、Boss 验收和重新开始；它不依赖隐藏快捷键，也不直接篡改私有状态。

## Alpha 02B 生存规则

- 玩家坦克装甲是唯一生命线，敌军和 Boss 只以玩家为战斗目标；
- 首次装甲耗尽消耗一次重启：等待 1.2 秒后原地恢复 50% 装甲，产生无伤击退并获得 2 秒保护；
- 重启耗尽后再次报废，本局失败；Boss 胜利会把装甲修满，但不会恢复重启次数；
- 炮弹可摧毁砖墙并反弹于钢墙，砖墙变化会同步刷新敌军 A* 导航；
- 清场后三选一协议、跨房间流程和旧 Boss 流程用于迁移对照；五波竞技场与即时升级尚未进入本迭代；
- 旧集成验收器中的 30 敌军、60 炮弹和 40 危险区域是历史性能基线，不是新玩法压力目标。

## 集中自检

```powershell
dotnet test ..\GodotTank.sln
godot --headless --path . --scene res://tests/integration/mvp_test_runner.tscn
```

自动化结果不能替代 Godot 可见试玩。重构期间会先建立新的可玩闭环，再在完整迭代结束时进行集中自检；新的全量压力测试安排在全部重构迭代完成后执行。
