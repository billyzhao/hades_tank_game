# 废土中继：Godot 可执行项目

Godot 4.7 .NET / C# 制作的俯视角坦克肉鸽项目。

## 版本边界

当前仓库中的可执行内容仍是**重构前历史 MVP / Alpha 01A 基线**：两张黄沙工业战斗房、三类普通敌军、跨房间中继站耐久、战场重启、三选一协议构筑，以及两阶段 Boss“路障指挥车”。它用于迁移对照和回归检查，不代表重构后的最终规则。

已经确认但尚未完成实装的目标版本是：

- 玩家坦克是唯一战斗主体，不存在独立中继站、基地血条或守卫结局；
- 一局包含 5 座竞技场，每座竞技场 5 波敌军，随后进入 1 场 Boss 战；
- 击杀经验推动战斗内即时升级，升级界面完全暂停战斗；
- 开局选择一种核心，核心固定操作节奏，同一核心支持约三条构筑路线；
- 统计强化、部门协议、维护奖励和 Boss 奖励共同组成受控随机构筑；
- 坦克原地重启，不回到基地或中继站旁。

完整目标以仓库根目录的移动核心竞技场策划、技术设计和路线图为准。

## 启动

从仓库根目录执行：

```powershell
dotnet build game1/Game1.csproj --nologo
godot --path game1
```

如果 Vulkan 管线异常，使用：

```powershell
.\game1\run-editor-opengl.cmd
.\game1\run-game-opengl.cmd
```

## 当前历史基线操作

- WASD / 方向键：移动
- 鼠标 / 右摇杆：独立瞄准
- 鼠标左键：射击
- 空格：冲刺
- Esc：暂停或继续
- F8：显示或隐藏调试信息（仅调试构建）
- Z：验收用玩家伤害
- X：验收用中继站伤害（仅历史基线，Alpha 02B 起移除）
- M：切换 SFX 静音

右上角“Boss 验收”按钮可直接进入历史 Boss 房，便于迁移前复核两阶段技能与胜利结算。

## 当前历史基线规则

- 中继站耐久、基地受击失败和中继站旁复活均为待移除的旧规则；
- 炮弹可摧毁砖墙并反弹于钢墙，砖墙变化会同步刷新敌军 A* 导航；
- 清场后三选一协议、跨房间流程和旧 Boss 流程用于迁移对照；
- 旧集成验收器中的 30 敌军、60 炮弹和 40 危险区域是历史性能基线，不是新玩法压力目标。

## 集中自检

```powershell
dotnet test ..\GodotTank.sln
godot --headless --path . --scene res://tests/integration/mvp_test_runner.tscn
```

自动化结果不能替代 Godot 可见试玩。重构期间会先建立新的可玩闭环，再在完整迭代结束时进行集中自检；新的全量压力测试安排在全部重构迭代完成后执行。
