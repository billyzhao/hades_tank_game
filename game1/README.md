# 废土中继：Godot 可执行项目

Godot 4.7 .NET / C# 制作的俯视角坦克肉鸽项目。

## 版本边界

Alpha 02 功能纵切已经完成：玩家坦克是唯一生命线，封锁城区具备五波、即时升级、核心/协议、辅助系统、四类敌军、精英和路障指挥车 Boss。

当前执行 **BC-01～BC-05 封锁城区可交付版收敛**：

- 玩家坦克是唯一战斗主体，不存在独立中继站、基地血条或守卫结局；
- 当前试玩版只包含封锁城区：5 波敌军、第 5 波精英和 1 场 Boss 战；
- 击杀经验推动战斗内即时升级，升级界面完全暂停战斗；
- 开局选择一种核心，核心固定操作节奏，同一核心支持约三条构筑路线；
- 统计强化、部门协议、维护奖励和 Boss 奖励共同组成受控随机构筑；
- 坦克原地重启，不回到基地或中继站旁；
- Boss 后进入封锁城区正式结算，不进入第二竞技场占位；
- 正式美术、特效、UI、音频、平衡和 Windows 构建在 BC-03～BC-05 完成。

BC-01～BC-04 已通过用户验收。当前进入 BC-05「最终平衡、压力与 Windows 构建」。启动后的正式流程为：标题入口 → 核心选择 → 五波战斗与波间构筑 → 路障指挥车 → 封锁城区胜利结算 → 重试或返回标题。

长期五竞技场架构继续保留，但后四区内容已经延期。当前范围以封锁城区收敛设计、技术设计和路线图为准。

## 启动

从仓库根目录执行：

```powershell
dotnet build game1/Game1.csproj --nologo
godot --path game1
```

如果 Vulkan 管线异常，使用：

```powershell
.\game1\run-editor-opengl.cmd
.\game1\run-game-opengl.cmd
```

## 当前操作与验收入口

- WASD / 方向键：移动
- 鼠标 / 右摇杆：独立瞄准
- 鼠标左键：射击
- 空格：冲刺
- Esc：暂停或继续
- F8：显示或隐藏调试信息（仅调试构建）
- M：切换全部音频静音

Debug 构建右上角“竞技场验收”按钮会展开策划验收菜单，可执行波次、升级、敌军、Boss、坦克报废和重新开始等快速验证；它不依赖隐藏快捷键，也不直接篡改私有状态。Release 构建不显示该入口。

## 当前生存与竞技场规则

- 玩家坦克装甲是唯一生命线，敌军和 Boss 只以玩家为战斗目标；
- 首次装甲耗尽消耗一次重启：等待 1.2 秒后原地恢复 50% 装甲，产生无伤击退并获得 2 秒保护；
- 重启耗尽后再次报废，本局失败；
- 炮弹可摧毁砖墙并反弹于钢墙，砖墙变化会同步刷新敌军 A* 导航；
- 每波刷新结束后必须清空残敌，再处理即时升级和波间奖励；
- 第五波精英清空后进入同图 Boss，当前交付版在 Boss 后进入正式单区结算；
- 30 敌军、160 炮弹和持续特效的交付压力目标在 BC-05 集中验证。
