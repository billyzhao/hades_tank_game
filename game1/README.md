# 废土中继：Godot 可玩原型

Godot 4.7 .NET / C# 制作的俯视角坦克肉鸽。当前版本包含两张黄沙工业战斗房、三类普通敌军、跨房间中继站总耐久、战场重启、三选一协议构筑，以及两阶段 Boss“路障指挥车”。

Alpha 01A 将战场统一为 FC 式上下攻防构图：中继站位于底部防区，敌军从上半区向下推进；玩家仍使用自由移动和独立炮塔。普通坦克约占一个 24 像素地图格。

## 启动

从仓库根目录执行：

```powershell
dotnet build game1/Game1.csproj --nologo
godot --path game1
```

如果 Vulkan 管线异常，使用：

```powershell
.\game1\run-editor-opengl.cmd
.\game1\run-game-opengl.cmd
```

## 操作

- WASD / 方向键：移动
- 鼠标 / 右摇杆：独立瞄准
- 鼠标左键：射击
- 空格：冲刺
- Esc：暂停或继续
- F8：显示或隐藏调试信息（仅调试构建）
- Z：验收用玩家伤害
- X：验收用中继站伤害
- M：切换 SFX 静音

右上角“Boss 验收”按钮可直接进入 Boss 房，便于快速验证两阶段技能与胜利结算。

## 核心规则

- 中继站总耐久跨房间保留，归零立即失败；
- 玩家装甲耗尽时优先消耗一次战场重启，1.2 秒后在中继站旁恢复 50% 装甲；
- 重启会清理复位点附近敌方炮弹，并提供 1.2 秒可见无敌保护；
- 重启耗尽后再次报废则本局失败；
- 清场后从三项协议中选择一项，再进入下一房间；
- 炮弹可摧毁砖墙并反弹于钢墙，砖墙变化会同步刷新敌军 A* 导航；
- Boss 在 50% 耐久时进入二阶段，击败后显示本局结算并写入最近一局摘要。

## 集中自检

```powershell
dotnet test ..\GodotTank.sln
godot --headless --path . --scene res://tests/integration/mvp_test_runner.tscn
```

集成验收器包含 30 敌军、160 炮弹和 40 危险区域的压力基线；自动化结果不能替代最终的 Godot 可见试玩验收。
