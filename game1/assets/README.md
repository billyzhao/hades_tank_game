# 原型表现资源

本目录存放《废土中继》的项目内可替换表现资源；规则脚本不得依赖资源文件名表达玩法语义。

- `art/actors/`：玩家、敌军与中继站。玩家车体按 32×32 逻辑像素显示；敌军按 24×24 显示。
- `art/tiles/`：沙漠工业地面、墙体和可复用场景装饰。
- `art/props/`：油桶、残骸等不参与碰撞规则的摆件。
- `vfx/`：炮口、拖尾、火花、碎片和爆炸。
- `audio/`：可替换的最小战斗音效。

导入要求：像素图使用 nearest 采样、关闭过滤和 mipmap；显示尺寸应为原始像素的整数倍或逻辑画布约定的半倍。当前 AI 原型资源只用于内部玩法验证，后续替换正式资源时必须更新来源登记。
