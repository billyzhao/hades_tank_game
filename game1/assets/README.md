# 游戏运行时素材

此目录只保存 Godot 实际加载的最终素材。原始下载包、购买凭证、Aseprite/PSD 工程、未筛选音频和 AI 生成源文件放在项目外的 `../../asset_sources/`。

## 命名规则

- 文件名使用小写 `snake_case`，例如 `tank_player_scout.png`；
- 动画图集加用途后缀，例如 `explosion_small_sheet.png`；
- 同一素材的资源文件与纹理共享主名称；
- 音频使用 `sfx_`、`music_`、`amb_` 前缀；
- 不使用作者原始的 `final2`、`new`、`copy` 等临时名称。

## 视觉导入规则

- 像素纹理关闭过滤与 mipmap；
- 优先使用项目统一色板，外部素材进入游戏前完成调色；
- 坦克车体、炮塔、炮口和履带动画保持可独立组合；
- 玩家、敌人、危险弹道和可互动物必须靠轮廓与明度区分，不能只靠颜色。

## 音频导入规则

- 游戏内优先使用 OGG，短促且高频触发的音效可使用 WAV；
- 原始高采样率文件留在 `asset_sources`，这里只保留处理后的版本；
- 同类音效准备少量变化，避免连续射击产生明显重复；
- 发布前统一响度并检查循环点。
